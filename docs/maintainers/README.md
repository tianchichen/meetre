# Maintainer documentation

这里保存帮助维护者和 coding agent 理解仓库的长期上下文与阶段记录，不是普通用户的使用入口。

- [`project-context/overview.md`](project-context/overview.md)：产品、交互、数据流和模块边界。
- [`development-logs/`](development-logs/)：按日期记录的开发阶段、验证结果和剩余风险。

用户安装和使用 Skill 请看 [`../../README.md`](../../README.md) 或 [`../user-guide.md`](../user-guide.md)。
